# Backlog — отложенные задачи

Список задач, сознательно отложенных (не забытых) в ходе работы над форком. Обновляется по
мере появления новых находок или решения текущих пунктов. Номера — внутренние идентификаторы
задач из рабочего трекера сессии, используются только для ссылок между обсуждениями.

## Баги

Специфичны для форка BlownChart (не унаследованы из апстрима).

- **#53** — Краш при перетаскивании иконки из меню приложений на рабочий стол, если отпустить
  палец до того, как шторка приложений успела закрыться. Стабильно воспроизводится.
- **#55** — В nightly-сборке `signingConfig` не подхватывается после апгрейда AGP
  (`nightly-release` в `ci.yml`). Возможно уже неактуально/разовая проблема — не подтверждалось
  повторно.
- **#65** — Remap ID виджетов при восстановлении резервной копии не реализован.
  Депприоритизировано: на практике виджеты после восстановления встают на место и без него.
- **#127** — Разовый краш при перетаскивании папки *с вложенными подпапками* из меню
  приложений на рабочий стол — только сразу после установки, до первого перезапуска
  лончера. Самоисцеляется после перезапуска (папка и её содержимое остаются на месте),
  при обычном использовании (не сразу после установки) не воспроизводится.
- **#139** — При включённой блокировке настроек переход в системный экран "Об приложении"
  (App Info) через контекстное меню приложения не работает: после ввода верного PIN
  вместо открытия App Info происходит возврат на домашний экран.
- **#140** — Перехват недавних приложений (Recents interception) работает некорректно:
  (а) когда переключаться не на что (в Recents больше ничего нет), повторно запускает
  последнее закрытое приложение вместо того, чтобы ничего не делать;
  (б) когда переключаться есть на что, сразу открывает второе по списку приложение,
  а не самое недавнее (первое).
