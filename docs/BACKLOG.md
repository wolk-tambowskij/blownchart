# Backlog — отложенные задачи

Список задач, сознательно отложенных (не забытых) в ходе работы над форком. Обновляется по
мере появления новых находок или решения текущих пунктов. Номера — внутренние идентификаторы
задач из рабочего трекера сессии, используются только для ссылок между обсуждениями.

## Баги

Специфичны для форка BlownChart (не унаследованы из апстрима).

- **#53** — Краш при перетаскивании иконки из меню приложений на рабочий стол, если отпустить
  палец до того, как шторка приложений успела закрыться. Воспроизводился только до первого
  перезапуска лончера после установки — как и #127 (см. ниже), что может указывать на общую
  первопричину. Судя по характеру бага, есть вероятность, что источник унаследован из
  апстрима Lawnchair, а не привнесён фичами форка. На практике стабильно проявляется только
  на одном конкретном устройстве с проблемной прошивкой, хроническими проблемами с памятью и
  ~1800 установленными приложениями — незначительная проблема, не в приоритете.
- **#55** — В nightly-сборке `signingConfig` не подхватывается после апгрейда AGP
  (`nightly-release` в `ci.yml`). Возможно уже неактуально/разовая проблема — не подтверждалось
  повторно.
- **#65** — Remap ID виджетов при восстановлении резервной копии не реализован.
  Депприоритизировано: на практике виджеты после восстановления встают на место и без него.
- **#127** — Разовый краш при перетаскивании из меню приложений на рабочий стол
  верхнеуровневой папки, *содержащей вложенную подпапку* (не самой вложенной подпапки,
  а её родителя) — только сразу после установки, до первого перезапуска лончера.
  Самоисцеляется после перезапуска (папка и её содержимое остаются на месте), при
  обычном использовании (не сразу после установки) не воспроизводится. На 100% не
  подтверждено, но похоже, что причина та же, что и у #53 (см. выше) — оба воспроизводятся
  только в одном и том же временном окне (до первого перезапуска после установки). Как и
  #53, стабильно проявляется практически только на одном конкретном проблемном устройстве —
  незначительная проблема, не в приоритете.
- **#140** — Перехват недавних приложений (Recents interception) работает некорректно:
  (а) когда переключаться не на что (в Recents больше ничего нет), повторно запускает
  последнее закрытое приложение вместо того, чтобы ничего не делать;
  (б) когда переключаться есть на что, сразу открывает второе по списку приложение,
  а не самое недавнее (первое).

## Расширения функционала

### Унаследованы из апстрима Lawnchair

Эти пункты — не личная инициатива, а идеи/задачи апстрима, которые было решено перенять
и адаптировать под форк (см. `docs/UPSTREAM_CONTRIB_NOTES.md`, ветка `16-dev`).

- **#42** — Дизайн поддержки нескольких icon-pack одновременно.
- **#44** — Оценить целесообразность разделения действий поиска по клику
  ("decouple search actions on click").
- **#45** — Оценить поддержку кастомных поисковых провайдеров в поиске дока.
- **#47** — Редизайн UX страниц настроек. Отложено на неопределённый срок ("когда-нибудь").

### Неофициальные пожелания от пользователей

Обратная связь после публикации SEO-описания и анонсов на профильных ресурсах — не
формальные issue, зафиксированы здесь для отслеживания.

- **#148** — Настройки чувствительности касания по иконке/папке и длительности нажатия,
  необходимой для начала перетаскивания.
- **#149** — Более короткий путь создания и редактирования папок в меню приложений — без
  обязательного захода в Настройки → Меню приложений → Папки в меню приложений.

### Личные идеи

- **#150** — Индивидуальная блокировка отдельных приложений PIN-кодом/отпечатком пальца, по
  аналогии с уже реализованной блокировкой настроек. Похожая функция уже есть в одном из
  альтернативных форков Lawnchair — предположительно на другой кодовой базе, требует
  проверки. Если будем реализовывать: обязательно упомянуть автора того форка как источник
  идеи.
